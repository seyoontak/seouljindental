# 서울진치과 홈페이지

경기도 안양시 동안구 **서울진치과** 공식 홈페이지입니다.
빌드 도구 없이 **HTML / CSS / JavaScript**만 사용하는 정적 사이트이며,
Cloudflare Pages에 그대로 올리면 바로 동작합니다.

---

## 1. 폴더 구조

```
.
├── index.html            # 페이지 전체 (한 장짜리 원페이지)
├── assets/
│   ├── css/style.css     # 스타일 (White / Dark Gray / Orange)
│   ├── js/main.js        # 모바일 메뉴 + JSON 데이터 렌더링
│   └── images/
│       ├── doctor-kimeunjin.jpg   # 대표원장 프로필 사진
│       ├── logo-lockup.svg        # 헤더 로고 (심볼+글자, 벡터)
│       └── logo.svg               # 치아 심볼만 (예비)
├── data/
│   ├── hours.json        # 진료시간  ← 여기만 고치면 됩니다
│   └── notice.json       # 공지사항  ← 여기만 고치면 됩니다
├── robots.txt
├── sitemap.xml
└── README.md
```

## 2. 자주 바꾸는 것

### 진료시간 바꾸기 — `data/hours.json`

```json
{
  "items": [
    { "day": "월 · 화 · 목 · 금", "time": "10:00 - 18:30" },
    { "day": "수요일 (야간진료)", "time": "14:00 - 21:00" },
    { "day": "일요일 · 공휴일", "time": "휴진", "closed": true }
  ],
  "lunch": { "time": "13:00 - 14:00", "note": "토요일은 점심시간 없음" },
  "note": "진료 마감 30분 전까지 접수해 주세요."
}
```

| 항목          | 설명                                                   |
| ------------- | ------------------------------------------------------ |
| `day`         | 왼쪽에 표시될 요일                                     |
| `time`        | 오른쪽에 표시될 시간                                   |
| `closed`      | `true`이면 주황색으로 표시 (휴진일 강조용, 생략 가능)  |
| `lunch.time`  | 표 **맨 아랫줄**에 회색 배경으로 표시                  |
| `lunch.note`  | 점심시간 아래 작은 글씨 (생략 가능)                    |
| `note`        | 표 아래 회색 박스에 표시                               |

> **진료시간은 이 파일에만 있습니다.** 임시 변경(연휴, 학회 참석 등)이 있어도
> 여기만 고치면 표·구글 검색결과 표기까지 모두 바뀝니다.
> 임시 안내는 `notice.json`에 공지로 함께 올리시면 더 확실합니다.

### 공지사항 바꾸기 — `data/notice.json`

```json
{
  "items": [
    {
      "date": "2026-08-07",
      "tag": "안내",
      "title": "제목",
      "body": "내용 (생략 가능)"
    }
  ]
}
```

- 목록은 **위에 적은 순서대로** 표시됩니다. 최신 글을 맨 위에 넣어주세요.
- `tag`는 주황색 라벨입니다 (`공지`, `이벤트`, `휴진` 등 자유롭게).
- 공지를 모두 지우면 "등록된 공지사항이 없습니다."가 표시됩니다.

> ⚠️ JSON은 쉼표(`,`)와 큰따옴표(`"`)를 정확히 지켜야 합니다.
> 수정 후 <https://jsonlint.com> 에 붙여넣어 문법 검사를 한 번 하면 안전합니다.

### 사진 바꾸기

`assets/images/` 안의 파일을 **같은 이름으로** 덮어쓰면 됩니다.
파일명을 바꿨다면 `index.html`의 `<img src="...">` 경로도 함께 수정하세요.

> 사진을 교체하면 `index.html`의 `<img ... width height>` 값도 실제 크기로
> 맞춰주세요. 이 값이 틀리면 로딩 중 화면이 밀립니다.
> (현재 `doctor-kimeunjin.jpg`는 1086×1449)

## 4. 로컬에서 미리보기

`data/*.json`을 `fetch`로 읽기 때문에 **`index.html`을 더블클릭해서 열면 공지·진료시간이
표시되지 않습니다** (브라우저 보안 정책). 아래처럼 간단한 로컬 서버로 열어주세요.

```bash
# Python이 설치되어 있다면
python3 -m http.server 8000
```

그다음 브라우저에서 <http://localhost:8000> 접속.

## 5. Cloudflare Pages 배포

1. <https://dash.cloudflare.com> → **Workers & Pages** → **Create** → **Pages**
2. GitHub 저장소를 연결하거나, 폴더를 통째로 **Direct Upload** 합니다.
3. 빌드 설정은 다음과 같이 둡니다.

   | 설정              | 값       |
   | ----------------- | -------- |
   | Framework preset  | `None`   |
   | Build command     | (비워둠) |
   | Build output dir  | `/`      |

빌드 과정이 없으므로 파일을 올리면 곧바로 반영됩니다.

## 7. 디자인 규칙

간판 디자인을 기준으로 한 3색 구성입니다. 색을 바꾸려면
`assets/css/style.css` 맨 위 `:root` 변수만 수정하면 사이트 전체에 반영됩니다.

| 용도            | 변수           | 값        |
| --------------- | -------------- | --------- |
| 포인트(주황)    | `--orange`     | `#E85A24` |
| 본문/헤더(진회색) | `--gray-900`  | `#2B2B2E` |
| 배경(흰색)      | `--white`      | `#FFFFFF` |

- 헤더 로고(`assets/images/logo-lockup.svg`)는 명함 원본(`REFS/namec_1.pdf`)에서
  **벡터를 그대로 추출한 것**입니다. 글자까지 실제 브랜드 폰트라 웹폰트로 흉내낸 것이
  아니며, 아무리 확대해도 깨지지 않습니다. 크기는 `.logo-lockup`의 `height`로 조절합니다.
  (`logo.svg`는 치아 심볼만 있는 버전으로, 필요할 때 쓰도록 남겨둔 파일입니다.)
- 지도는 **8번 항목** 참고. 키를 넣기 전까지는 키가 필요 없는 기본 지도가 표시되고,
  길찾기 버튼은 항상 네이버지도로 연결됩니다.
  지도 위의 `서울진치과 2F` 이름표는 지도 데이터가 아니라 직접 얹은 것입니다
  (개원 전이라 아직 어느 지도에도 등록되어 있지 않기 때문).
- 모바일 우선 반응형 (768px / 1024px 브레이크포인트)
- 애니메이션은 버튼 호버와 메뉴 아이콘에만 사용 (`prefers-reduced-motion` 대응)
- 모바일에서는 화면 하단에 **전화 / 이메일 / 길찾기** 고정 바가 항상 노출됩니다

## 8. 지도를 네이버 지도로 바꾸기

네이버 지도는 **iframe으로 페이지에 삽입할 수 없습니다.** `map.naver.com`이
`X-Frame-Options: DENY`를 내려보내서 브라우저가 차단합니다. 구글 지도처럼
주소만 넣으면 되는 embed 코드가 네이버에는 없습니다.

따라서 네이버 지도를 쓰려면 **네이버 지도 JS API**를 써야 하고, 여기에는
무료 Key ID가 필요합니다. 코드는 이미 다 들어가 있으니 **키 한 줄만 채우면**
자동으로 네이버 지도로 바뀝니다.

### 발급 순서

1. <https://console.ncloud.com> 가입 후 로그인
2. **Services > Application Services > Maps** 이동
3. **Application 등록** 클릭
   - Application 이름: 아무거나 (예: `seouljin-web`)
   - **Web Dynamic Map** 체크
   - **Web 서비스 URL**에 배포 도메인 등록
     (예: `https://seouljindental.com`, 로컬 테스트용으로 `http://localhost:8000`도 함께)
4. 등록 후 발급된 **Key ID** 복사

### 적용

`assets/js/main.js` 맨 위의 `keyId`에 붙여넣으면 끝입니다.

```js
var NAVER_MAP = {
  keyId: '여기에붙여넣기',        // ← 이 줄만 채우면 됩니다
  lat: 37.37300,
  lng: 126.95820,
  zoom: 17,
  ...
};
```

- 위치가 실제 건물과 다르면 `lat` / `lng` 숫자를 조정하세요.
  (네이버지도에서 해당 위치 우클릭 > '이 위치의 좌표 복사'로 확인 가능)
- `zoom` 숫자를 키우면 더 확대됩니다.
- **서비스 URL에 등록하지 않은 도메인에서는 지도가 뜨지 않습니다.**
  도메인을 바꾸면 콘솔에서 URL을 추가해 주세요.
- 키가 잘못됐거나 지도를 불러오지 못하면 자동으로 기본 지도가 그대로 표시되므로,
  페이지가 깨지지는 않습니다.

## 9. 고쳤는데 화면이 그대로일 때 (캐시)

`assets/css/style.css` 나 `assets/js/main.js` 를 고쳤는데 사이트에 반영되지
않는다면 **브라우저 캐시** 때문입니다. Cloudflare Pages는 CSS/JS 파일을
4시간 동안 캐시하도록 강제하며, `_headers` 로도 덮어쓸 수 없습니다.

### 해결: `index.html` 의 버전 숫자를 올린다

```html
<link rel="stylesheet" href="assets/css/style.css?v=1">
<script src="assets/js/main.js?v=1" defer></script>
```

`?v=1` 을 `?v=2` 로 바꾸면 브라우저가 새 파일로 인식해 즉시 받아갑니다.
**CSS나 JS를 고칠 때마다 이 숫자를 1씩 올려주세요.** (두 줄 모두)

### 내 화면에서만 급히 확인하고 싶다면

- Windows: `Ctrl` + `F5`
- Mac: `Cmd` + `Shift` + `R`
- 또는 시크릿 창에서 열기

> `index.html`, `data/*.json`, 이미지는 이 문제가 없습니다.
> HTML과 JSON은 항상 최신을 확인하고, 이미지는 파일명을 바꾸면 바로 반영됩니다.

## 10. 검색 등록 (구글 / 네이버)

사이트를 만들어두는 것만으로는 검색에 나오지 않습니다. 아래 두 곳에 등록해야
검색엔진이 수집해 갑니다. **소유확인 코드는 본인 계정으로만 받을 수 있으므로,
받으신 코드를 알려주시면 `index.html` 에 넣어드립니다.**

### 10-1. 구글 서치콘솔

1. <https://search.google.com/search-console> 접속 → 구글 계정 로그인
2. 왼쪽 위 **속성 검색 > 속성 추가**
3. **`URL 접두어`** 선택 (오른쪽) → `https://seouljindental.com/` 입력 → 계속
   - 왼쪽 `도메인` 방식은 DNS 설정이 필요하지만 www 까지 한 번에 처리됩니다.
     Cloudflare에서 DNS를 관리 중이면 이쪽도 괜찮습니다.
4. 소유권 확인에서 **`HTML 태그`** 펼치기 → 아래 같은 줄을 복사

   ```html
   <meta name="google-site-verification" content="여기에긴문자열" />
   ```

5. 이 줄을 `index.html` 의 `<head>` 안에 넣고 저장 → 배포 완료까지 1~2분 대기
6. 서치콘솔로 돌아와 **확인** 클릭
7. 확인되면 왼쪽 메뉴 **색인 생성 > Sitemaps** → `sitemap.xml` 입력 → **제출**
8. 맨 위 **URL 검사** 에 `https://seouljindental.com/` 입력 → **색인 생성 요청**

### 10-2. 네이버 서치어드바이저

1. <https://searchadvisor.naver.com> 접속 → 네이버 로그인
   (병원 계정 `seouljindental@naver.com` 으로 하시는 것을 권합니다)
2. 오른쪽 위 **웹마스터 도구** 클릭
3. 사이트 입력창에 `https://seouljindental.com/` 입력 → 오른쪽 화살표 클릭
4. **소유확인** 창에서 **`HTML 태그`** 선택 → `<meta name="naver-site-verification" ...>` 복사
5. 위와 같이 `index.html` 의 `<head>` 에 넣고 배포 → **소유확인** 클릭
6. 확인되면 왼쪽 메뉴에서 순서대로
   - **요청 > 사이트맵 제출** → `sitemap.xml` 입력 → 확인
   - **요청 > 웹 페이지 수집** → `https://seouljindental.com/` 입력 → 확인
   - **검증 > robots.txt** → 수집 가능 여부 확인

### 10-3. 네이버 스마트플레이스 (지역 검색에는 이게 가장 중요)

동네 치과는 "안양치과", "평촌치과" 같은 검색에서 **지도·플레이스 영역**에
노출되는 것이 검색 순위보다 훨씬 중요합니다. 홈페이지 등록과는 별개입니다.

1. <https://smartplace.naver.com> 접속 → 네이버 로그인
2. **신규 등록 > 업체 등록**
3. 사업자등록증, 의료기관 개설신고증명서 등 서류 제출 (심사 며칠 소요)
4. 등록 후 진료시간·사진·전화번호를 홈페이지와 동일하게 맞춥니다
5. 등록이 끝나면 **플레이스 URL**을 알려주세요.
   홈페이지의 '네이버지도로 보기' 버튼과 지도 마커를 실제 플레이스로 연결해 드립니다.

### 참고: robots.txt 가 리포지토리 내용과 다르게 보입니다

Cloudflare가 AI 크롤러 차단 문구를 자동으로 앞에 붙이기 때문입니다.
**검색엔진(구글봇·네이버 Yeti)은 차단되지 않으므로 SEO에는 문제가 없습니다.**
`Sitemap:` 줄도 그대로 살아 있습니다.
원치 않으시면 Cloudflare 대시보드 > 해당 도메인 > **AI Crawl Control** 에서 끌 수 있습니다.
